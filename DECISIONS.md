- Build a credible premium fashion-store demo for a real Yunusobod retailer.
- It must prove both visual quality and persistent authenticated admin CRUD.
- The retailer has not formally commissioned or approved the website.
- User approves significant visual and business choices; agent outputs must be reviewed.

- Three distinct visual approaches before selecting one; avoid cloning references.
- Evaluate selective GSAP and optional 3D through experiments and performance tests.
- Start with a single product-to-publish vertical slice, then larger UX.
