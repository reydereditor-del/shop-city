# SHOP CITY — Agent instructions

Read PROJECT_BRIEF.md, DESIGN_SYSTEM.md, ARCHITECTURE.md, DECISIONS.md and PROGRESS.md before any implementation. Work only in this repository. If a prerequisite or platform permission is missing, report it rather than silently fabricate success.

## Quality bar
This must NOT become a generic AI storefront. Propose and compare art-directed layouts. Use legally licensed, approved media. Preserve high performance, accessible mobile UX and functional product administration. Prefer measured evidence to adjectives such as "premium" or "bug-free."

## Safe workflow
1. Inspect branch, tree, changes, permissions and relevant docs.
2. Restate task, constraints, concrete exit criteria and assumptions.
3. Make scoped changes on a feature branch; do not overwrite unrelated edits.
4. Run type, lint, build, relevant tests and browser/visual checks when tooling exists.
5. Clearly separate observed passes from unverified claims.
6. Update PROGRESS.md and HANDOFF.md with exactly what changed, evidence, blockers and next task.
7. Request review before merging to main. Never force push, delete data, publish a site, or enable live payments without authorization.

No secrets or genuine customer information in repository, screenshots or logs. Never treat mock catalog data as verified retailer inventory.
